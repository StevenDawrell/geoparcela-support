# GeoParcela – Support

Public support & privacy repository for the **GeoParcela** Chrome
extension – a buildability check for Spanish land that overlays
official government geodata (Catastro, SIU planning classes, flood
zones, protected areas, PVGIS) on idealista, Fotocasa and Google
Maps and turns it into a plain-language verdict per parcel.

> The extension's source code is **not** public. This repository only
> hosts the privacy policy and the issue tracker.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml)

In the extension: right-click the toolbar icon → *Extension options* →
*Developer info* → **Run diagnostics**, then **Report a bug**.
That copies a privacy-safe diagnostic report (no coordinates, no
licence key, no personal data) — paste it into the issue form.
